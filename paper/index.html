Predicting Search Impression Decline with Machine Learning

A decision-support approach for prioritizing content review using anonymized search-performance data

Machine Learning Capstone · FlyRank ML Internship

Abstract

This study asks whether historical search-performance signals can help prioritize client-content items that subsequently experience a meaningful decline in Google Search impressions.

Using anonymized FlyRank warehouse data from March 2026, the analysis aggregates daily records into client-content observations and uses March 1–15 as the feature period and March 16–31 as the outcome period.

A content item is labeled as declining when its average daily impressions fall by at least 20% between the two periods.

A Random Forest classifier is compared against a simple rule-based baseline using ROC-AUC on a held-out test set.

The Random Forest achieved a ROC-AUC of 0.6408, compared with 0.5184 for the baseline, an observed improvement of 0.1224.

1. Introduction / Problem Statement

Search-performance teams often need to decide which content items deserve attention first. When many content items are available for review, treating every item equally can make prioritization difficult.

This project investigates whether historical search-performance signals can be used to rank content according to the likelihood of a subsequent impression decline.

Decision supported: The resulting system is intended to help prioritize content-review work. Higher-risk items can receive earlier human investigation, while lower-risk items can remain under monitoring.

This project does not attempt to prove how Google's ranking algorithm works. It also does not estimate the causal effect of refreshing or changing content.

3. Methodology

Unit of Analysis

Each observation represents one unique combination of an anonymized client and content item.

Predictive Features

Features are calculated exclusively from the March 1–15 feature period.

  • Average daily impressions
  • Daily clicks
  • Click-through rate
  • Average search position
  • Daily sessions
  • Engagement rate
  • Engagement time per session

Outcome Definition

The target is a binary operational label.

A content item receives a label of 1 when its average daily impressions decline by at least 20% between the feature and outcome periods.

The two periods contain different numbers of days, so impressions are normalized into average daily impressions before calculating the percentage change.

Baseline

The rule-based baseline combines two first-period signals:

  • Impression-level risk
  • Search-position risk

The combined score assigns content to MONITOR, REVIEW, or REFRESH_NOW priority groups.

Machine-Learning Model

A Random Forest classifier is trained using only first-period predictive features.

Validation

The dataset is divided into an 80% training set and a 20% held-out test set using stratified sampling and a fixed random seed of 42.

ROC-AUC is the primary metric because the goal is to rank content items according to predicted decline risk.

Accuracy, precision, recall, and F1-score are used as secondary evaluation metrics.

Leakage Checks

Variables describing the second period are excluded from the predictive feature set. The notebook also checks predictive features for missing values and examines client overlap between the training and test sets.

4. Results

The Random Forest and rule-based baseline were evaluated using the same held-out test set.

Result: The Random Forest outperformed the rule-based baseline under this evaluation design, improving ROC-AUC by 0.1224.

This result indicates stronger observed ranking performance on the held-out test set. It should not be interpreted as evidence of a causal effect on Google rankings or traffic.

Feature Signals

The Random Forest feature-importance analysis was used to examine which first-period signals contributed most to the model's predictions.

Feature importance is interpreted as a model diagnostic rather than proof that any individual signal causes search-performance changes.

5. Ranked Recommendations

The model output is converted into a content-review prioritization system.

REFRESH_NOW

Items with the highest predicted probability of future impression decline. These should receive the earliest human review.

REVIEW

Items with moderate predicted decline probability. These should be investigated before deciding on an action.

MONITOR

Items with lower predicted decline probability. These can remain under observation while higher-priority items are investigated.

Reason Codes

  • WEAK_SEARCH_POSITION — relatively weak first-period search position.
  • LOW_CTR — relatively low first-period click-through rate.
  • LOW_SEARCH_VISIBILITY — relatively low first-period impression volume.
  • GENERAL_DECLINE_RISK — elevated predicted risk without one of the specific reason codes dominating.
Important: These recommendations are decision-support outputs. A REFRESH_NOW recommendation does not mean that refreshing a page will cause Google rankings or impressions to increase.

6. Limitations & Honest Framing

  • The analysis measures observed associations between historical signals and subsequent impression changes.
  • The constructed outcome is an operational definition based on a 20% decline in average daily impressions.
  • The analysis uses March 2026 data and therefore represents a limited observation window.
  • Performance may differ across other time periods, content types, websites, or search environments.
  • The validation uses a random stratified train/test split. Client overlap was examined rather than assuming that the observations were completely independent.
  • The results do not establish causal relationships between content changes and search performance.
  • The model should therefore be used for prioritization and human review rather than as an automatic decision-maker.
